agentring

Browsers only allow the microphone on HTTPS pages (or localhost). Open this page over HTTPS to talk on calls.

Pair this browser

Run agentring pair on the computer where your agent runs and paste the pairing code it prints.

This tab rings while it is open. Calls arrive over the relay's WebSocket; there is no push, so a closed tab can't ring (use the Android app for that).

No microphone: you can listen, but the others can't hear you.
